Kind: **missing** = required but absent; **different** = present but not as specified; **extra** = present but not asked for. Severity: **high** = blocks the demo deployment or breaks a stated rule; **medium** = a real gap with a workaround; **low** = cosmetic or a documented, deliberate choice.
